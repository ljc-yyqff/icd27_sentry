## 高速取消与恢复

以下四个记录全部通过，`events.jsonl` 还包含独立 TF 观测：

- `red_cancel/`：进入红侧顶板下时取消，实际峰值约 1.803 m/s；安全停车并保持低姿。
- `red_resume/`：从上述取消位置继续，完整车体离洞后才恢复高度。
- `blue_cancel/`：进入蓝侧顶板下时取消，实际峰值约 1.800 m/s；安全停车并保持低姿。
- `blue_resume/`：从上述取消位置继续，完整车体离洞后才恢复高度。

取消用例的 Nav2 状态为 `CANCELED`（5），恢复用例为 `SUCCEEDED`（4）。
取消后的实际升降行程分别约 0.055002、0.055000 m，实际速度均降到 0.00001 m/s 以下。
取消与恢复不会重置仿真或发布测试工具自己的升降/速度命令。

## 修复内容和边界

- 三维物理真值替代平面真值作仿真 TF 来源，保留加速、自旋、升降时的实际高度与倾角，
  避免地面投影成临时障碍；旧平面接口仍保留。
- RMUL2027 使用完整物理足迹的配置空间 A*，局部跟随使用补密路径与安全近前瞻；
  隧道侧墙和低障碍不被清除。
- 两侧使用同一套行为树：开阔接近允许普通运动及重规划，到等待点后才停车对齐；
  窄引导段、压低、净空确认、穿越与恢复高度均由行为树管理。
- 控制器和最终守卫遇到“恒速预测越过目标撞到远处边界”时只缩放平移速度，
  保留必须的航向控制，仍验证完整车体的一秒扫掠；无安全候选时停车。
- 升降、云台或局部净空短暂异常时低姿停车，稳定恢复后只继续剩余路段；
  持续异常 5 s 则失败并保持低姿，不跳过反馈保护。
- 正常导航、接近、穿洞上限同为 1.8 m/s，精细居中为 0.2 m/s。没有缩小碰撞包络、
  隧道侧墙或预测时域。停车、对齐、升降以及有障碍时的减速仍然存在。

本次不是实车 LIO、坡地/台阶、所有任意目标或动态障碍组合的完整验收。
麦轮仍使用简化圆柱和低摩擦近似，不是滚子接触的高保真模型。
普通模式经过 CAD 地面接缝的对照记录在 `physical_stall_probe/`。
