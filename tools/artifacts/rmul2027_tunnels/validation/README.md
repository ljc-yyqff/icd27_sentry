## 测试条件

- ROS 2 Humble、Gazebo 无界面物理仿真，`ROS_DOMAIN_ID=91`，独立 `IGN_PARTITION`。
- `world:=rmul_2027`、`use_composition:=True`、默认 Gazebo 真值定位。
- 升降行程 `0.055 m`，位置容差 `0.002 m`，穿洞限速 `0.2 m/s`。
- 完整碰撞包络为 `0.72 × 0.72 m`；未缩小机器人或放大隧道。
- 麦轮接触是低摩擦圆柱与车体驱动力的简化模型（`mu=mu2=0.01`），
  升降伺服 `Kp=20000, Ki=20000, Kd=800`，力限幅保持 `±2000 N`。
- 红侧首次测试从默认出生点 `(-4.8, 3.5)` 启动；蓝侧测试前仅将同一隔离实例
  移到洞外 `(0.425, -3.475)`。各次穿洞／取消／续行之间不重置升降关节。

## 使用与边界

正常使用无需运行验收工具，也无需手动发升降命令。重启 Gazebo 和导航后，
在 RViz 发送 `Nav2 Goal` 即由行为树调度过洞。启动命令见项目根目录 `ICD_LAUNCH.md`。

真值链路只验证当前 CAD 平地段；平面底盘真值不含坡地真实高度、横滚与俯仰。
未验证实车 LIO、实际升降硬件、真实附着／打滑或任意场景的可通行性。
遇到障碍、反馈持续失效或动作失败，系统停车并保持洞内低姿，而非盲目绕障或抬升。
